# Foundry

Initial Apple Multiplatform (iOS + macOS) SwiftUI client for Foundry.

## Current Scope

- Sign in with `POST /auth/token`
- Session refresh with `POST /auth/refresh`
- API health check with `GET /health`
- Authenticated user list with `GET /users`
- Auto-restore session from local storage
- Auth tokens stored in Keychain (with migration from prior local `UserDefaults` tokens)

## Run

1. Start the Foundry API (`apps/api`) locally.
2. Open `apps/apple/Foundry/Foundry.xcodeproj` in Xcode.
3. Pick an iOS Simulator or a macOS destination and run.

## API Config

The app reads values from Info.plist keys generated by build settings:

- `FOUNDRY_APP_ENV` (`local`, `staging`, or `production`)
- `FOUNDRY_API_BASE_URL` (default: `http://localhost:8000`)
- `FOUNDRY_API_BASE_URL_LOCAL`
- `FOUNDRY_API_BASE_URL_STAGING`
- `FOUNDRY_API_BASE_URL_PRODUCTION`
- `FOUNDRY_API_VERSION` (default: `v1`)

`FOUNDRY_API_BASE_URL` remains as a compatibility fallback. Per-environment URLs are used first.

You can also override any of these values using Xcode scheme environment variables (for example, set `FOUNDRY_APP_ENV=staging` for a staging run).

If you run on a physical iOS device, set the active environment base URL to a reachable LAN URL for your API host.
